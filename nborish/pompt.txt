### Requirements

1. **Complete Functionality**

   * Inspect the entire existing project before making changes.
   * Fix all build errors, runtime errors, console errors, broken imports, missing dependencies, broken routes, and non-functional buttons.
   * Make sure every navigation link and interactive element works.
   * Ensure project cards, resume buttons, contact buttons, social links, and other CTAs function correctly.

2. **Professional Developer Design**

   * Make the UI look like a high-quality professional developer portfolio.
   * Use a clean, modern, technical aesthetic rather than an overly decorative design.
   * Maintain strong visual hierarchy, spacing, typography, alignment, and consistency.
   * Make the portfolio immediately communicate that I am a **Full-Stack Developer and AI/ML Engineer**.
   * Give projects, technical skills, experience, education, achievements, and contact information strong visual presentation.
   * Use subtle gradients, glass effects, borders, shadows, code/technical visual elements, or other modern techniques only where they improve the design.
   * Avoid excessive visual effects that make the website look unprofessional.

3. **Fully Responsive**
   The entire website must work perfectly on:

   * Large desktop
   * Standard desktop
   * Laptop
   * Tablet
   * Mobile
   * Small mobile screens

   Check and optimize:

   * Navbar
   * Hero section
   * About section
   * Skills
   * Projects
   * Experience
   * Education
   * Achievements
   * Contact section
   * Footer
   * Cards
   * Buttons
   * Typography
   * Images
   * Spacing
   * Animations

4. **Animations & Interactions**
   Add professional, smooth animations throughout the portfolio:

   * Hero entrance animation
   * Scroll reveal animations
   * Smooth section transitions
   * Project card hover animations
   * Skill/card hover effects
   * Button hover and click feedback
   * Navbar transitions

   * Smooth
   * Fast enough to feel responsive

5. **Navigation**

   * Make the navbar fully functional.
   * Desktop and mobile navigation must work correctly.

   * Add smooth scrolling.
   * Ensure navbar behavior works correctly while scrolling.

6. **Projects**
   Make the projects section one of the strongest parts of the portfolio.
   Each project should clearly show:

   * Project name

8. **Performance**

    * Test every interactive component.
